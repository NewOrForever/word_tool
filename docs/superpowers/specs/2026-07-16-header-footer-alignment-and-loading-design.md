# 页眉页脚位置与加载优化设计

## 目标

- 页眉和页脚分别选择左对齐、居中或右对齐
- 修改页眉页脚后清理不再使用的旧图片和失效链接
- 保持正文、正文图片以及未修改的页眉或页脚不变
- 重新生成主程序和安装包

## 界面

- 页眉内容输入框右侧增加位置选择，选项为左边、居中、右边，默认左边
- 页脚内容输入框右侧增加位置选择，选项为左边、居中、右边，默认右边
- 只有当前处理方式会修改对应内容时，位置选择才参与处理
- 页眉和页脚一起修改时，两项位置分别生效

## 文件处理

- 新增或替换页眉页脚文字时，按各自选择写入位置
- 清理被替换页眉页脚自己的旧链接
- 清理仅被这些旧链接使用、并且确认没有被文档其他位置使用的旧图片
- 不删除正文或其他部位仍在使用的图片
- 保持现有的拖拽、文件夹递归处理和原文件就地处理方式

## 异常处理

- 无法识别或结构不完整的 Word 文件继续给出失败说明，不覆盖成损坏文件
- 只有完整处理成功后才替换原文件
- 单个文件失败不影响同一批次中的其他文件继续处理

## 验证

- 自动验证页眉和页脚的左、中、右三种位置
- 自动验证页眉和页脚可以选择不同位置
- 自动验证失效链接和不再使用的旧图片被清理
- 自动验证仍被正文使用的图片不会被删除
- 使用附件中的 128 个 Word 副本批量处理，检查文件完整性和残留链接
- 抽样使用 Word 实际打开处理后的文件并记录耗时
- 验证主程序和安装包自检通过
